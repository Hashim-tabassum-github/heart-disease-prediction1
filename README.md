# Heart Disease Prediction

This is a **Flask-based web application** that predicts the likelihood of heart disease based on user input. The model used is a **logistic regression model**, and the input features are preprocessed using a saved **scaler and label encoders**.

## Features
- **User-friendly UI**: A simple web form for entering patient details.
- **Pre-trained ML Model**: Uses a logistic regression model to predict heart disease.
- **Data Preprocessing**: Applies scaling and label encoding before making predictions.
